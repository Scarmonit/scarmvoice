      Voice & Audio

      Voice

      Speak and watch the bar. If nothing moves, pick a different microphone above or check that Windows is letting apps use it.

      Input Profile

      Push to Talk

      Greeting & Leaving

      When someone joins or leaves the call, everyone in it hears a spoken announcement — "name has joined the channel". Leave a box empty to be announced by your username; fill it in and the channel hears your words in place of your name. Letters and spaces only, up to 20 characters.

      How loud you have to be before ScarmVoice shows you as speaking — the marker on the meter above. To gate your microphone itself, use Push to talk.

      Notifications

      Overview

      Enable Desktop Notifications For per-channel notifications, use the bell in the channel header — or right-click the channel in the list.
      Enable Taskbar Flashing Flashes the app in your taskbar when you have new notifications.
      Do Not Disturb Silences every notification, sound and badge until you turn it off.

      Sounds

      New Message
      New Message in the channel I'm currently reading
      Voice Join & Leave The spoken join and leave announcements. Only audible while you are in the call — set your words in Voice & Audio → Greeting & Leaving.
      Disable All Notification Sounds Disables every sound above, including voice join and leave. Your individual choices are kept and restored if you turn this off.

      Badges

      Unread count on the taskbar button The number drawn over the app's icon in the taskbar. Muted channels are never counted.

      Advanced

      Per-channel notification settings. The same three levels the bell in the channel header offers, and any channel muted for a while.

      Custom emoji

      Shared with everyone on the board — the website and the phone app see the same set. Type :name: in a message, or pick one from the emoji button.

      Layout

      Edit Mode Move, resize and hide every part of the window, and keep arrangements as named layouts. Everything is done from the Edit Mode panel — this button is only the way in.
      Saved layouts Each one remembers where every element is, how big it is and whether it is shown. Up to 10.

      Chat

      Formatting

      Show formatting as you type Draw bold, italics, links, quotes and code in the message box while you write them. Your message is still Markdown — this only changes how the box looks, never what is sent.
      Keep the formatting bar open Remember the Format toolbar between messages instead of starting each session with it hidden.

      Message Box

      Recall previous messages With the message box focused, Ctrl+↑ steps back through the last 25 messages you sent and Ctrl+↓ steps forward again. Plain ↑ and ↓ always move the caret, so this never gets in the way of editing a multi-line message.

      Color & Contrast

      Saturation Reduce the saturation of colours in the app, for those with colour sensitivities. This does not affect images, video or attachments.
      Enable High Contrast Mode Enhance visibility with bolder text, brighter borders and sharper contrast.

      Reduced Motion

      Enable Reduced Motion Stops animations and transitions throughout the app. On automatically when Windows is set to reduce motion.

      Audio & Screen Reader

      Announce new messages Reads incoming messages out with your screen reader. Off unless you use one — it makes the conversation an assertive live region.
      Notification and join/leave sounds are in Notifications.

      Screen share

      Privacy

      Blocked people
      Blocking hides someone's messages and silences them in voice, on this computer only — the board has no server-side block, so they are not told. Right-click a message to block its author.

      System

      General

      Automatically open ScarmVoice when your computer starts up
      Start ScarmVoice minimized Start ScarmVoice in the background, out of your way.
      Minimize ScarmVoice to System Tray Clicking X minimizes ScarmVoice instead of closing it completely.
      Enable Hardware Acceleration Uses your GPU to make ScarmVoice run more smoothly. Turn this off if you are seeing visual glitches. Needs a restart.
      Join voice automatically on launch Connects you to the voice channel as soon as the app opens.
