Edit Mode: snapping you can switch off, and options on every element

**"Snap to Elements" now actually switches snapping off**

It did nothing you could see. Turning it off stopped elements lining up with each
other, but the window's own edges were still in the list and the grid was still
catching every drag regardless — so an element let go anywhere near a side still
jumped, and the toggle read as broken.

Two separate questions, and now two separate switches:

- **Snap to Grid** — whether a drag lands on the grid. New, and on by default,
  which is how it behaved before.
- **Snap to Elements** — whether edges and centres line up with the other
  elements *and* with the window's edges. Off now means off.

Turn both off and an element lands exactly where you let go of it, to the pixel.

**The panel is shorter: two columns of checkboxes**

The show/hide list ran down a single column, which made the panel taller than a
lot of windows — and the footer, where Save and Revert All Changes live, is at
the bottom of it. The checkboxes sit in two columns now, the way the reference
arranges them. Same list, about a fifth less height.

**Right-click any element for its own options**

Right-clicking an element in Edit Mode opens a small panel of the adjustments
that element actually has — the equivalent of the reference's per-frame menus.
There is also a **More options…** button beside the selected element.

Depending on what is being adjusted, that panel offers:

- **Orientation** — Horizontal or Vertical, for the things that have a direction:
  the servers rail, the me bar, the channel header and the message box. Turn the
  me bar vertical and its name and its controls stack instead of sitting in a
  row.
- **Order** — Normal or Reversed, for anything with contents to reorder. Reverse
  the channel header and its actions move to the other end.
- **Width** and **Height** sliders, in per-cent of the window, with the number
  beside them.
- **Shown** — the same switch as the checkbox in the list, where you are already
  looking.
- **Revert Changes** — undo everything done to *that element* since Edit Mode
  opened, leaving every other element alone.
- **Reset To Default Position** — put that one element back where the default
  arrangement has it.

An element is only offered what it has. The member list has no meaningful
orientation, so it is not given one, and the message area is offered neither
orientation nor order — a control that does nothing is worse than no control.

**Also**

- Right-clicking an element also selects it, so the outline tells you which one
  the panel is about.
- The options panel is placed at the pointer and pulled back inside the window,
  because right-clicking something near an edge is the common case.
- Eighteen more tests, including that both snap toggles genuinely change where a
  drag lands, that reverting one element leaves the others where they are, and
  that an orientation set back to its own default leaves no trace behind.
