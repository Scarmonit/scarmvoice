Twenty lines of real editor, not one stretched one

**The tall box had one enormous line in it**

The last release gave a new code block twenty lines of height and gave them to
the wrong line. The room was hung underneath the last line of code — and a line
in this editor owns whatever hangs from it, so that one line became 361 pixels
tall. Its text was stretched down the whole block, and the cursor, which is
always drawn the height of the line it sits on, became a bar running the full
height of the box.

**Now it is twenty ordinary lines**

The room hangs above the block's closing edge instead, which is a line the
cursor can never be on. So:

- **A new code block opens about twenty lines tall** at the normal line height,
  numbered from 1, empty and ready to type into — a code editor pre-sized to
  twenty lines.
- **The cursor is one line tall again**, wherever it is.
- **Lines fill in normally as you type** — 1, 2, 3 — all the same height, and
  the block keeps its shape until your code outgrows it, then grows and scrolls
  as before.

**Text is no longer flagged red as you type it**

Half-written code was being coloured bright red — a string you had opened but not
closed, a regular expression you were in the middle of. That red came from the
editor's stock colour scheme, which paints anything a language calls an "error",
and while you are typing that is most things.

Nothing in the message box is painted as an error any more. A message box is not
a linter, and code being written is not code that is wrong.
