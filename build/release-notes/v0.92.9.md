Two downloads of the same name no longer land on the same file

**Saving files**

- **Two files with the same name, downloaded at the same time, no longer overwrite each other.** Saving a picture called image.png while another download of that same name was still going sent both of them to the same place. The app asked whether the name was free before it started fetching, and fetching takes long enough that both downloads were told the same thing — so both wrote to it, and what was left afterwards was neither of them. Both still said they had saved successfully, so nothing on screen suggested anything had gone wrong. Each download now takes its name before it begins, so the second one becomes "image (2).png" — which is what it was always meant to do, and what it already did for a file that was sitting there beforehand.
- A download that fails still leaves nothing behind, so a save that did not work never sits in your Downloads folder wearing the name of one that did.
