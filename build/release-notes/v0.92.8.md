A direct message marks one place, not two

**Direct messages**

- **A DM no longer puts a red mark on the ScarmVoice server icon as well.** One message from one person lit both marks at once — a 1 beside the @ button, and a 1 on ScarmVoice for a server where nothing had been posted. Clicking through to see what it wanted showed a channel list with nothing unread in it, and the mark stayed there until the conversation was read. The @ button is where conversations live and the server icon is where channels do; each one now counts only what belongs to it.
- The taskbar button still counts everything, as it should. When the window is minimised or sitting in the tray there is no rail to divide, so its number remains the total — a direct message included.
