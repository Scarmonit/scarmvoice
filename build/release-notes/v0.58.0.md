The tap that left your microphone on

A full audit of the app and the server behind it, end to end. Twenty-odd things, and one of them was listening.

**Push to talk**

- A short tap could leave your microphone OPEN. If you let go before the mic had finished starting — which takes a moment the first time in a call — the release was thrown away, and the app then showed a quiet microphone icon over a live one for the rest of the call. Pressing Mute during that same moment failed the same way.
- Everything that opens and closes the microphone now happens in order, so a release can never be lost behind the press it was cancelling.
- A mute or deafen hotkey Windows refuses to give us says so, instead of sitting in Settings looking bound.

**Voice messages**

- They record from the microphone you picked in Settings. They were using whatever Windows calls the default, so anyone with a headset selected was sending clips from their webcam.
- Clicking the mic button twice no longer leaves a second microphone open for the rest of the session.

**Direct messages, and being told about them**

- DMs, DM notifications and an admin's "end this call" could all silently go nowhere for a whole session. The connection that carries them is opened before you sign in on some launches, and it had no way to say who it belonged to afterwards. It reconnects properly now.
- A reaction, an edit or a pin in another channel no longer counts as an unread message and no longer pops a "New message" notification for a message nobody wrote.
- Posting from your phone no longer notifies you about your own message on the desktop.

**Messages**

- "Alice is typing…" no longer reappears underneath the message Alice just sent, sometimes for a minute.
- A message you send while offline belongs to YOU. If it was still waiting when you signed out, it used to go out later under the next person to sign in on that computer, under their name.
- Unread counts are kept per account, so two people sharing a computer no longer inherit each other's.
- A link inside a code block stays code — no preview card, no image.
- The same link in two different messages shows a preview on both, not just the first.

**Search**

- A search that failed says so, with a Try again, instead of looking exactly like "nothing matched".
- A full page of results says it is showing the newest forty rather than claiming that is all there are.
- Opening More filters over a date like `before:2026` no longer deletes it when you press Apply, and `has:audio` survives the round trip.

**Settings**

- Turning AI noise suppression off now updates the Input Profile above it. It used to leave "Clear Voice" selected and unclickable, so there was no way back to it without switching to something else first.
- Starting a 2FA setup and then touching anything else in the same panel no longer wipes the QR code — which was worse than a re-click, because the entry already on your phone was dead.
- Changing your profile picture updates both places it appears, not one.
- A search that matches nothing says so instead of emptying the list.

**Keyboard and screen readers**

- The per-channel bell and gear, and every row in the members list and the voice roster, can be reached and used with the keyboard. Per-person volume and "Mute for me" had no keyboard path at all.
- The message menu opened with Enter can be walked with the arrows, and Escape gives focus back.
- Every message the app shows in the corner — errors, confirmations, "Copied" — is announced now.

**Files**

- An upload that fails gives the file back to the composer instead of dropping it. For a pasted screenshot or a recording, those bytes were the only copy.
- A dropped connection during an upload says so in words rather than "fetch failed".
- A file that is still being written while it uploads no longer fails outright.

**Windows**

- "Start minimized to the tray" no longer quietly turns off "open maximised" for anyone who uses both.
- An update that has downloaded and is waiting for your call to end no longer forgets itself if you press Check for updates in the meantime.

**On the server**

- Any member could permanently delete any other member's attachment, profile picture or custom emoji. Fixed.
- Claiming an install id no longer hands over the message history written from it.
- Closing your account now deletes your profile photo instead of leaving it in storage.
- Deleting a member's account no longer leaves their photo behind either.
