The message box is a real editor now

**Why this was worth doing**

A run of problems in the message box all had one cause: it was an ordinary text
field with a picture painted behind it, so every behaviour a code editor gets
for free had to be written by hand here — and hand-written behaviours break one
at a time. The cursor lagging behind what you typed, the arrow keys leaving a
code block, Tab walking off to another button, an empty code block you could not
get rid of: four symptoms, one root.

The message box is now built on a real code editor. The cursor, the arrow keys,
Tab, selection, copy, paste and undo all come from it. There is nothing left for
this app to get wrong about them.

**Nothing about your messages changed**

Your messages are still Markdown, and now more literally than before: the
editor's document IS the Markdown. What you see in the box is the text that gets
sent, character for character. Every message ever posted still reads exactly as
it did.

**What you should notice**

- **The cursor keeps up.** It is the editor's own cursor now, in the same text
  it is drawing — there is no second copy of your message to fall out of step
  with.
- **Undo is better.** It survives the formatting buttons, and it survives the
  app writing into the box.
- **Code blocks behave like code.** Arrow keys stay in the code, Tab indents and
  Shift+Tab outdents, and the block still names its language, numbers its lines,
  colours its code in the same palette a posted message uses, and turns
  spellcheck off.
- **An empty code block still goes** on one more backspace, and the fences still
  cannot be eaten by accident while there is code between them.
- **Everything else is where it was.** The formatting toolbar, @mentions, Ctrl+↑
  message recall, per-conversation drafts, pasting, dropping a file, and the
  right-click spelling menu all work as before.

**Also**

- Formatting marks dim as you type them — the stars around a bold word, the
  arrow on a quote, the hashes on a heading — so the syntax and the words are
  easy to tell apart.
- The editor is loaded from the app itself; nothing new is fetched from the
  internet, and the app still runs entirely offline.
