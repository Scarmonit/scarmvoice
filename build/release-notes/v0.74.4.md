Compact message display, in the two places it was not

**Compact did nothing at all in direct messages**

*Settings → Accessibility → Chat Message Display → Compact* puts a timestamp and
a name on every line and takes the avatars out, so more of the conversation fits
on screen. It has worked in a channel for a long time.

In a direct message it did nothing whatever. Turning it on changed the channel
behind the conversation and left the conversation itself exactly as it was —
avatars, spacing and all — so the two columns of the same app disagreed about a
setting with one switch.

Conversations follow the setting now, including the date dividers between days.

**Compact left thread replies with no name and no timestamp**

The thread drawer was styled for Compact but still bundled consecutive replies
from the same person under one header, the way the roomier setting does. Compact
removes the avatar column, and that column is the only place a bundled reply
carries anything identifying it — so a run of replies from one person came out
as bare lines of text with no author and no time on any of them but the first.

Every line in a thread now carries its own name and time, which is what Compact
means everywhere else.

**Also**

- The stylesheet is checked against all three message lists now, so a list that
  is told to go compact and has no rules behind it cannot ship again — and the
  app is driven through a real conversation and a real thread to confirm nothing
  is bundled when the setting is on.
