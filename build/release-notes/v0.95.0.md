Double-tap Escape to clear a message, and an @mention list with everybody in it

**The message box**

- **Double-tap Escape to clear what you have typed.** Two presses in quick succession empty the message box, in a channel or in a conversation. A single press is never enough, so a stray Escape leaves your message where it was.
- **Ctrl+Z brings it straight back.** Clearing is an edit like any other, so the editor's own undo restores the message — and the send button with it — if you did it by accident.
- **Everything Escape already did, it still does first.** A popup, a menu, the @mention list, a picker, a modal or an open message editor is always what Escape takes off first, and that press never counts as half of a double-tap. The clear only happens when Escape has nothing else to mean and the caret is in a box with something in it.
- While you are part-way through a message in a conversation, Escape is now about the message rather than the conversation. Empty the box, or click away from it, and Escape closes the conversation exactly as it always did.

**@mentions**

- **Everybody can be mentioned now, whatever their status.** The list only ever held people who were online or who had said something since the app started, so anyone offline was unmentionable — you typed their name and the autocomplete simply had no such person in it. It is built from the full member list now, so online, idle, do-not-disturb and offline all appear.
- **The list shows real profile pictures.** Somebody with a picture on every other surface in the app was drawn here as two letters on a coloured disc. It is the same face as everywhere else now, with the initials still underneath it while the picture loads — and for anyone who hasn't set one.
- Names that **start** with what you have typed come first, then the rest alphabetically, which matters now that the list has the whole membership to choose from.
- An @mention of somebody offline also reaches them properly: the hint that travels with the message, and decides whether a channel set to "only @mentions" says anything, now knows about them too.
