The red underline now leads somewhere

Misspelled words have been underlined in the message box since the app existed. There was just never anything you could do about it.

**Spellcheck**

- Right-click an underlined word and the menu lists the words you probably meant, at the top. Click one and it replaces the typo where it stands.
- **Add to dictionary** for names, in-jokes and whatever game everyone is playing this month, so they stop being flagged. It goes into Windows' own dictionary, so it sticks — and the underline disappears straight away.
- A correction is an ordinary edit, so Ctrl+Z takes it back.
- Nothing is sent anywhere and nothing is downloaded. It uses the spellchecker Windows already has, in whatever language your machine is set to, so it also works with no connection at all.

**Right-click in any text box**

- Cut, Copy, Paste and Select all are on every text field now, not only the message box — the thread reply, the box you edit a message in, the search field. Right-clicking those used to do nothing at all.
- They grey out when they would have nothing to do, and the menu opens the moment you press the button instead of pausing first to go and look at the clipboard.
