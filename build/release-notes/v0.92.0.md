One view at a time — and a fine-grit polish pass over the theme

**Direct Messages no longer overlap the server view**

Switching to Direct Messages used to layer the conversation over the
still-visible channel — both views rendered at once, stacked. The DM
place covered the server view rather than replacing it, which held only
while every surface was opaque; a custom theme's translucent surfaces let
the channel read straight through. The server view now genuinely stops
rendering the moment the DM place opens — driven by the same single
switch that opens it, so the two can never disagree — and your scroll
position in the channel is exactly where you left it when you come back.

**The theme's brightness matches the reference exactly**

Pixel-matching the container interiors against the reference showed the
whole sheet a uniform step too dark. The global dim is recalibrated, so
your colours land at the reference's exact register — the containers were
already true zero-overlay, and stay that way.

**Solid glyphs, like the reference draws them**

The voice card's buttons, the hang-up, the attach, emoji and send icons
now render in the filled style instead of thin outlines — same icons,
same functions, heavier ink. The me-row's glyphs soften from stark white
to the reference's grey-white, and the message box placeholder mutes to
match.

**A dozen measured details**

- Edit Channel is a neutral raised plate, not an accent colour
- The welcome "#" sits on its subtle circular disc again under themes
- The attach + moved in to the reference's inset
- Corners on the input bar and voice card tightened to 5px; their border
  is now a whisper, not a line
- The signal icon rides a lighter rounded chip; "Voice Connected"
  drops a font weight; the subtitle truncates with an ellipsis
- The online dot is smaller, with a dark separating ring
- The conversation keeps a permanent scrollbar thumb, styled to the
  theme — the side lists still auto-hide theirs

**In short**

- DMs fully replace the server view; scroll positions survive the swap
- Sheet brightness recalibrated to the reference's measured values
- Filled icon style across the voice card and composer
- The measured polish list: badge, button colour, insets, corners,
  borders, chip, weights, dot, scrollbar
