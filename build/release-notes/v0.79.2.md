A code block you can see the bottom of

**Eight lines and a wall**

The message box stopped growing after about eight lines of code. You could keep
typing — the text was going in, and it sent correctly — but you could not see it.
There was no scrollbar, the wheel did nothing, and the cursor disappeared off the
bottom edge and stayed there. Anything past line 8 was written blind.

**Now it grows, and then it scrolls**

- **A short block stays short.** Three lines of code is a three-line box, the way
  it always was.
- **It grows as you write**, line by line, up to thirty lines tall.
- **Past thirty lines it stops growing and starts scrolling**, with a scrollbar
  down the right-hand side — the same quiet one the message list and the member
  list use.
- **The view follows your cursor.** Type line 40 and you are looking at line 40.
  It no longer sits at the top of the block while you work at the bottom of it.
- **You can scroll back through the whole thing** with the wheel, the scrollbar,
  or the arrow keys, and nothing is out of reach.

Thirty lines is around six hundred pixels, so on a small window the box stops a
little earlier — enough is always kept for the conversation above it. Maximise
the window and you get the full thirty.

**Also**

- This applies to the whole message box, not only to code: a long message grows
  and scrolls the same way.
- Nothing changed about what gets sent. The message is still exactly the text in
  the box.
