**There is no message length limit any more**

- The composer used to stop accepting text at 2000 characters. Pasting a long message — a whole chat session, a transcript, a wall of logs — got cut off partway through with nothing on screen saying why, and no way to finish it.
- Paste as much as you like now. The only limit left is 250,000 characters, which is roughly a hundred and twenty times the old one, and if you somehow go past it you are told exactly how long the message was instead of having the end of it quietly thrown away.
- That applies to the thread reply box and to editing a message you have already sent, not just the main composer.
- Long messages were also made to render properly rather than merely be allowed: a huge paste no longer makes the app stutter while you type, and a giant code block is left as plain text rather than spending a second colouring it in.

**Numbered lists count up again**

- A numbered list came out with every single item showing "1." — paste a list of eight things and you got eight number ones. It happened whenever there was a blank line, an indented sub-point, or a wrapped line anywhere in the list.
- Lists now number the way they were written: 1, 2, 3, and so on. A list that starts at 5 starts at 5. A list where every line was typed as "1." still counts 1, 2, 3, which is what markdown means by it.
- Sub-lists sit inside the item they belong to instead of cutting the list in half, and they change marker as they go deeper — 1. then a. then i., bullets then hollow bullets then squares.
- The rest of the formatting was brought in line with Discord at the same time: ***bold italic*** together (it used to leave a stray asterisk behind), __underline__, _italic_ with single underscores — while leaving snake_case_names alone — double-backtick code spans, # ## ### headings, -# small text, and the triple-arrow quote that quotes everything after it. A list or a heading inside a quote is now still a list or a heading.

**Right-click a misspelled word and you get corrections**

- The red underline led nowhere on some machines: right-clicking a misspelled word showed Cut / Copy / Paste and no suggestions at all. Chromium was hiding the corrections from the app on purpose, expecting a menu it builds itself to go and ask for them afterwards — so there was never anything to show.
- Misspell "toulp" now and the menu offers tool, tolu, toil, tools, Toul — every suggestion, each one its own line. Click one and it replaces the word.
- **Add to dictionary** is there for names, in-jokes and anything else it does not recognise, and it teaches Windows too, so the word stops being underlined everywhere.
- **Undo** and **Redo** were added to the menu. They are the real ones, so undoing works whether you use the menu or Ctrl+Z — including taking back a spelling correction.
- All of it is in the app's own menu with the app's own styling. Nothing native pops up.

**Pinned messages are a panel now**

- Clicking the pin in the channel header used to drop a strip in above the conversation, pushing everything down, showing one clipped line per pin, and staying there until you closed it.
- It opens a proper **Pinned Messages** panel over the conversation instead. Every pin is a card with the sender's picture, their name, the date and time, and the whole message — formatted, so a pinned list or a pinned block of code reads the way it does in the channel.
- Hover a card and **Jump** appears, which takes you to that message where it sits in the channel. **Unpin** is right beside it.
- It closes on the X, on Escape, by clicking anywhere outside it, or by switching channel — and it no longer sits over one channel showing another channel's pins.

**A bar that tells you what you missed**

- Open a channel with messages you have not seen and a bar appears across the top: *"12 new messages since 12:38 AM on March 21, 2026"* — how many, and where you left off.
- Click the bar to jump straight to the first message you have not read.
- **Mark As Read** on the right clears it and the channel's badge with it. It also goes away when you leave the channel, and when you write something in it — if you are posting, you have read it.
- Your own messages never count towards it, and neither do messages from anyone you have muted.
