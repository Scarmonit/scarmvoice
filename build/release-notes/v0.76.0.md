Rearrange the window, format what you write, and get your last message back

**Formatting, shown as you write it**

The message box has a **Format** button beside the emoji and microphone. It
opens a toolbar: bold, italic, underline, strikethrough, bulleted and numbered
lists, quote, headings, inline code, links, spoilers, and a code block with the
language chosen from a menu.

Formatting is now drawn in the box as you type. Bold text is bold while you are
writing it, a quote is set as a quote, a link is coloured, the marks themselves
are dimmed beside what they apply to. Nothing about the message changed: it is
still Markdown, it is still the text in the box, and it is exactly what everyone
receives. The box has simply stopped hiding what that text means until you press
Enter.

Everything the field could do before, it still does — selection, undo, spell
check, dragging files onto it, pasting. The toolbar writes the same characters
you would have typed, so Ctrl+Z undoes a button the way it undoes a word.

- **Ctrl+B, Ctrl+I, Ctrl+U** and **Ctrl+K** are what they are everywhere else.
  **Ctrl+Shift+X** opens and closes the toolbar, **Ctrl+Shift+7/8/9** make a
  numbered list, a bulleted list and a quote, and **Ctrl+Alt+C** opens the code
  block menu.
- **A button with nothing selected** puts the cursor between the marks, so the
  next thing you type is the formatted thing.
- **Pressing a button again takes the formatting off.** On a list or a quote,
  choosing a different one replaces the marker rather than stacking two.
- **The toolbar lights up** for whatever the cursor is currently inside, so
  "am I typing in bold" is something you can see.
- **Two switches in Settings → Chat** turn the live formatting off, and keep the
  toolbar open between sessions.

**Code blocks with a language on them**

The code block button asks which language before it inserts anything, because
the language is what decides how the block is coloured. Anything selected
becomes the body of the block.

Sent, a code block now arrives titled: the language it was written in, a **Copy**
button, and numbered lines down the left. Blocks written before this release
look the same way — it is how they are drawn, not something stored with them.
A fence written by hand with an unusual language still says what you wrote.

**A window you can rearrange**

*Settings → Appearance → Layout* has an **Edit Layout** button. It puts the app
into an edit mode where the channel list, the member list, the me bar and the
message box are outlined and can be dragged.

Sections snap into zones rather than landing wherever they are dropped. Pick one
up and only the places it can go are shown; let go over one and it moves there.
That is deliberate: every arrangement it can produce is one that was laid out on
purpose, so there is no way to end up with panels overlapping, a section half off
the edge, or a window that has to be reset to be usable.

- **The channel list and the member list** trade sides.
- **The me bar** stays under the channel list or becomes a bar across the top.
- **The message box** sits below the messages or above them.
- **Cancel or Escape** puts back the arrangement you started with; **Reset**
  returns to the default.

**Layout templates**

An arrangement can be saved by name — up to ten — and brought back from
*Settings → Appearance*. Saving is offered from inside edit mode as well, so an
arrangement can be kept the moment it looks right.

**Getting a message back with Ctrl+↑**

With the message box focused, **Ctrl+↑** brings back the last message you sent,
and again for the one before it, up to the last twenty-five. **Ctrl+↓** comes
forward again.

Deliberately not the plain arrow keys: those still move the cursor, which
matters in a message longer than one line.

- **A half-written message is kept.** Walking back stashes it, and coming
  forward past the newest entry hands it back.
- **Both ends stop rather than wrap**, because wrapping is indistinguishable
  from a keypress that did not register.
- **Editing the box ends the walk** — from there it is yours again.
- **It can be turned off** in *Settings → Chat*, where the history can also be
  cleared. Signing out clears it regardless: it is a record of what you typed,
  and the next person to sign in on this machine must not be able to read it.

**A note on colours and font sizes**

The reference toolbar this is modelled on also offers text colour, highlighting
and a font-size menu. Those are missing here on purpose. Your messages are
Markdown — that is what the app stores, what it sends, and what every message
ever posted already is — and Markdown cannot express a colour or a point size.
Adding them would have meant sending messages as something else. Headings are
the honest version of a size control, and they are on the toolbar.

**Also**

- The resize strip on each side panel follows its panel when the two swap sides,
  and dragging it still widens the panel in the direction you are pulling.
- Every one of these is covered by tests — 92 new ones, including a check that
  the text drawn under the cursor is character-for-character the text in the
  box, and that every arrangement the layout editor can reach is one the
  stylesheet actually describes.
