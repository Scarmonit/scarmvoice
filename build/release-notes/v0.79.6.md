A new code block really does open twenty lines tall

**This is the third go at it, and this time it is the block**

Twice this was fixed by making the message BOX twenty lines tall, and twice what
came back was the same picture: a code block one line high sitting in the top of
a tall empty message box. The box was never the thing. The room has to belong to
the block.

**Now it does**

- **A code block you have just made is twenty lines tall** — a title bar and
  twenty lines of room to write in, rather than a single slot you have to fill
  before you can see anything.
- **Real lines take the room back as you write them.** Five lines of code leaves
  fifteen lines of space; at twenty the block is full and grows normally from
  there.
- **It still stops and scrolls at thirty lines**, exactly as before.
- **Nothing is added to your message.** The room is drawn, not typed: a block
  with one line of code in it still sends one line of code. It would have been
  much easier to pad the block out with blank lines, and every one of them would
  have gone out with the message.

**Also**

- Typing in a code block is still as quick as it was made in the last release —
  a millisecond a keystroke in a forty-line block.
- Last release's notes had a piece of stray markup in them that showed up as
  asterisks in the release history. Fixed, there and here.
