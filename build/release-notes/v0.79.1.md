The bottom of the window is back where it belongs

**The "…" menu opened in the wrong corner**

Pressing the **…** button in the formatting toolbar opened its menu — Link, Code
block, Spoiler, Clear formatting — down in the bottom-left corner of the window,
on top of your name and your microphone controls, nowhere near the button that
opened it.

It opens beside its button again, the way it always did.

**And it shoved the whole app upwards**

The same fault had a second half that was easy to blame on something else: while
that menu was open it counted as part of the page rather than a layer over it, so
everything else had to make room. The channel list, the message history, the
formatting toolbar and the message box all jumped up by the height of the menu,
and dropped back when it closed.

Nothing moves now. Opening the menu changes nothing but the menu.

**Also**

- The menu's own rows are drawn properly again — one line each, with the keyboard
  shortcut set quietly to the right instead of stacked underneath in oversized
  type.
- A code block's own **…** menu is fixed by the same change, and clicking its
  language chip no longer closes the language list you were about to pick from.

Nothing about writing or sending a message changed. This is the window's layout
only — the editor added in 0.79.0 is untouched.
