A private note on a profile, and the rest of the action row

**You can leave yourself a note about someone**

The profile card ends with **Note (only visible to you)** — click it and type. It stays on this computer and is never sent anywhere, which is what "only visible to you" ought to mean. It saves as you pause, and again if you close the card mid-sentence.

**The action row is no longer one button**

- **Message** is the right height now and carries a speech bubble, so it reads as an action rather than as a label.
- A **…** button beside it holds everything else about that person: Message, Copy user ID, and Block or Unblock when there is something to block.

**Spacing and proportions**

- The banner is taller, and the picture's overlap point moved with it.
- The facts underneath — Status, Role, Account — sit further apart, and each label has more room above its value. Three pairs pressed together read as one block.

**One more button changed colour**

**Create DM** in the find-or-start panel is blue-violet now, like every other primary action in the app. It was the last teal one.
