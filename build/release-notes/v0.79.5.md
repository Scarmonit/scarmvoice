Typing in code that keeps up, and sections that scale

**Typing in a code block was slow, and now it is not**

Every keystroke in a code block was taking 55 milliseconds on a forty-line
block — the delay you could feel between pressing a key and seeing the letter.
The app was redrawing the whole block's decoration on every character: clearing
a marker off every line of the block and putting it straight back, a line at a
time.

Typing a character does not move a code block, so now that redraw only happens
when the block itself changes. **A keystroke in a forty-line block costs one
millisecond instead of fifty-five**, which is the same as typing in an empty
message box.

**Enter and Shift+Enter swap over inside a code block**

- **Enter** starts a new line, the way it does in every code editor.
- **Shift+Enter** sends the message.

Outside a code block nothing changes: Enter still sends and Shift+Enter still
makes a new line. Half-written code no longer goes out the moment you finish a
line of it.

**A code block opens twenty lines tall**

It used to open one line tall, so you were writing into a slot you had to fill
before you could see anything. It now opens as a proper editor and grows from
there, still stopping and scrolling at thirty lines. On a short window it opens
as tall as there is room for.

**Edit Layout: making a section bigger makes the section bigger**

Resizing a section only ever grew the frame. The me bar's avatar, name and
buttons stayed exactly the size they were, sitting in a corner of a larger and
emptier panel.

- **Drag a corner and the section zooms** — the avatar, the text and the icons
  all grow with the panel, in proportion, the way they would if you zoomed into
  that part of the window.
- **Drag an edge and it is a plain resize**, as before. Contents scale in both
  directions at once or not at all, so the gesture that scales them is the one
  that changes both.
- **Or say it outright**: there is a new **Scale** control in the right-click
  options, from 25% to 400%, which takes the panel along with it. It is also the
  way back to 100% if a drag went too far.
- **It is saved with the layout**, along with position, size, orientation and
  show/hide, and Reset To Default Position puts it back to normal size.
