Direct messages stop being a second-class channel

**Moderation now works in DMs**

- **An Owner or Admin can delete somebody else's message in a direct message.** Until now this simply did not work: the button was not there, and the server would have refused it anyway. Right-click the message and choose **Delete (moderator)** — the same place, with the same name, as in a channel.
- **The same goes for editing one.** **Edit (moderator)** is offered on somebody else's message in a conversation now, and the message says who changed it afterwards: *"edited by …"*, exactly as a channel message has for a while. Nobody rewrites what you said in a private conversation without it being visible.
- **Only in conversations you are actually in.** This is the important limit and it is enforced on the server, not by hiding a button. Being the Owner does not let you reach into two other people's private conversation — you can moderate the conversations you are a member of, and nothing else. The check runs before your role is even looked at.
- **Nothing changes for everybody else.** A member still edits and deletes only their own messages, in a DM and in a channel alike, and still pins anything in a conversation they are in.

**Why this was broken, and why it should stop happening**

Direct messages and text channels were built twice. They looked the same on screen — one component draws both — but underneath there were two of everything: two sets of rules, two ways of deleting a message, two ideas of who is allowed to do what. So every feature had to be built twice, and the second one was usually built later, after somebody noticed it was missing. Pins, threads, search, reactions and the *(edited)* marker all arrived in channels first and in conversations months afterwards. Moderation was the last one on that list.

That is fixed at the root rather than patched again. There is now one message system that both use, so a rule written once is a rule that holds in both places, and a DM is simply a channel with a guest list. Three things that were quietly different are now the same:

- **Deleting a message with a file attached** now removes the file from storage in a conversation too. It did not before — the file stayed behind forever, unreachable, up to a gigabyte at a time.
- **Deleting a message that has a thread** takes the thread with it identically in both places.
- **Reacting, pinning and editing** all run through the same code, so they can no longer disagree about anything.

**Also**

- The *(edited by …)* marker is now carried on direct messages, in the app and on the phone.
