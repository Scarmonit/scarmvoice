An empty code block can be deleted again

**The block would not go away**

Holding backspace through a code block deleted the code and then stopped. What
was left was the shell — a title bar, one numbered line and a bottom edge — with
nothing in it and no obvious way to be rid of it.

Worse than it looked, too. The next press was eating the line break between the
code and the fence, which put the cursor *inside the title bar*, where the text
is invisible. From there every further press deleted a character of the
```` ```javascript ```` nobody could see, and letting go halfway left a broken
fence behind.

**Now**

- **One more press on an empty block removes the whole thing** — title bar,
  numbered line, bottom edge and all — and puts the cursor back in the message
  where the block was. If the block was the only thing in the message, the
  message box is simply empty again.
- **The gap closes behind it.** No blank line left where the block used to be.
- **It works from anywhere in the block**, and from either key: backspace or
  delete.
- **An unclosed block** — a ```` ``` ```` typed and then thought better of — goes
  the same way.

Holding backspace from the end of a code block now runs straight through the
code, takes the block with it and carries on into the text above, which is what
holding the key down was asking for.

**While there is still code in it**

The fences are the panel's own edges now, not text you are meant to be editing —
so backspace at the very start of the first line, and delete at the very end of
the last, do nothing rather than quietly damaging a block you cannot see the
edges of. Empty the block first and it goes in one press.

**A fence you are typing is visible while you type it**

Typing ```` ``` ```` used to hide what you were writing the moment the block
appeared, so the language went in blind. The title bar now steps aside for as
long as the cursor is on that line, and takes over again when you leave it.

**Also**

- Removing a block is one edit, so one Ctrl+Z brings it back.
- Nothing about the format changed. A code block is still an ordinary Markdown
  fence with a language tag.
