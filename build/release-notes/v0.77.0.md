Edit Mode: move, resize and hide every part of the window

**A real editor, not a few switches**

*Settings → Appearance → Edit Mode* now opens a proper editing state, modelled on
the one in retail World of Warcraft. The interface stops responding to ordinary
clicks, a grid appears behind it, every element it can place is outlined and
labelled, and a control panel appears to drive the lot.

This replaces the arrangement editor from the last two releases rather than
sitting beside it. That one could only put a section into one of a handful of
fixed slots, which is why the me bar looked movable and refused every target and
the message box could not be moved at all. Everything is a rectangle now — a
position and a size — so those two move like anything else, and so does
everything that could not be touched before.

**The control panel**

- **Layout** at the top: choose which saved layout is in use, and make, rename or
  delete one.
- **Show Grid**, and a **Grid Size** slider from 4 to 96 with the number beside it.
  Elements snap to whatever pitch you set.
- **Snap to Elements**: with it on, an edge you drag also lines up with the other
  elements' edges and centres, and a guide appears where it caught.
- **A checkbox for every element**, grouped into *Panels*, *Bars* and *Details*.
  Unticking one hides it; ticking it brings it back.
- **Revert All Changes** and **Save** at the bottom.

The panel can be dragged anywhere by its title bar, and stays where you left it.

**What can be moved, resized and hidden**

The servers rail, the channels list, the member list, the message area, the
channel header, the me bar and the message box — all seven can be dragged
anywhere and resized from any edge or corner. Three more can be shown or hidden:
the typing indicator, the header's search box and the formatting bar.

- **Select an element** by clicking it. It gets a solid outline, eight resize
  handles, and its size and position appear in the panel with **Hide** and
  **Reset this** beside them.
- **Every element has a minimum size**, so nothing can be squeezed down to
  something unusable, and nothing can be dragged off the edge of the window.
- **Positions are proportional**, so an arrangement survives a resized window or
  a different monitor instead of drifting off the edge.
- **Bars sit above panels, and the message area is the backdrop.** Drag the me bar
  into the middle of the chat and it stays visible rather than disappearing
  behind it.

**Saved layouts**

Save an arrangement under a name — up to ten — and switch between them from the
dropdown, or from *Settings → Appearance*. Each one remembers the position, the
size and the shown/hidden state of every element, so recalling it puts the window
back exactly as it was.

**Default** is always there, cannot be renamed or deleted, and is what *Use the
default layout* returns to. Saving while it is selected asks for a name and makes
a new layout rather than writing over it.

**Nothing changes unless you change it**

The default arrangement is still the window this app has always drawn, laid out
the same responsive way. Edit Mode does not take that over: the moment you
actually move or resize something, the arrangement is measured off the screen
exactly as it stands and becomes the starting point — so nothing jumps at the
moment you begin, and anybody who never opens Edit Mode is not affected by any of
it.

**Leaving**

- **Save** keeps the arrangement and stays in Edit Mode.
- **Revert All Changes** puts back the layout you came in with.
- **The X, or Escape**, leaves. If there is unsaved work it asks first rather than
  quietly throwing away several minutes of arranging.

**Also**

- Layouts saved under the previous two releases used the old slot model and
  cannot be translated into rectangles; they are dropped and the window returns
  to the default. There were at most a few days in which to make one.
- Sixty-one tests cover this, including that the switch to custom placement moves
  nothing on screen, that an element cannot be resized below its minimum or
  dragged out of the window, and that a saved layout restores position, size and
  visibility for every element.
