A formatting bar laid out like the reference, and a code editor in the message box

**The toolbar, control for control**

The formatting bar now carries the same controls in the same order as the app it
is modelled on:

**B** *I* U S — bulleted list, numbered list — quote, highlight, text size, more
— and a bin at the far end.

- **Highlight** writes inline code. Markdown has exactly one way to put text on a
  coloured plate, and that is it.
- **Text size** is a menu of Markdown's three heading levels, and it ticks the one
  the cursor is already on. There is no point size to offer: headings *are*
  Markdown's type scale.
- **More** holds Link, Code block, Spoiler and **Clear formatting**, which strips
  every mark off the selection — the line markers as well as the inline ones.
- **The bin** throws the message away, with what is attached to it. It asks first.

Everything still writes Markdown into the same box. What is sent is the text in
the message box, and the renderer that draws it is the one this app has always
had.

**A code block is now an editor while you write it**

Type or insert a fenced block and the message box turns into a code editor:

- **A title bar on the block** with the language on it — *JavaScript*, *Python*,
  whatever the fence says. Click it to change the language; the fence is rewritten
  under you and the cursor stays where it was.
- **A "…" on the block** with *Change language*, *Copy code* and *Remove code
  block*, which takes the fences off and leaves the code as ordinary lines.
- **Numbered lines** down the left.
- **Syntax highlighting** as you type, from the same highlighter that colours a
  sent message.
- **The backticks stop showing.** The opening line becomes the title bar and the
  closing one becomes the block's bottom edge. They are still there, still part
  of the message, still what gets sent — you simply stop having to look at them.
- **The whole box switches to the code face** while it holds a block, because a
  message with a code block in it is mostly code.

Several blocks in one message each get their own title bar, and an unclosed block
gets one too — it is still a block.

**On the two things that did not come across**

- **Text colour.** Markdown cannot express a colour, and this app stores and sends
  Markdown. A colour button would either do nothing or quietly turn your message
  into something else. The highlighter writes inline code instead, which is the
  nearest thing the format actually has.
- **Italics in the message box** are still shown by tint rather than by slanting.
  Slanting reshapes the letters, and that is exactly what used to walk the cursor
  away from the text you were typing. The sent message is properly italic.

**Also**

- The message box and the layer that draws the formatting are measured against
  each other in a real window now, character by character, including inside a
  code block with the gutter and the code face in play. The worst drift over a
  full line is a twentieth of a pixel.
- A partly-loaded highlighter used to take the whole preview down with it. It
  degrades to plain text now, like a missing one.
- Three tests that render tens of thousands of elements, or boot a whole app per
  case, got their own timeouts. They were landing on the default and passing or
  failing according to how busy the machine was rather than according to anything
  they were testing.
