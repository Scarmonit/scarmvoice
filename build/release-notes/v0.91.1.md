The glow finds its frame — floating cards in a dark field

**The bottom of the window reads the right way round**

The last release let the gradient glow across the whole bottom of the
window in one bright band. The reference does the opposite, and now so do
we: the dark chat and sidebar surfaces run all the way to the window's
bottom edge, and the full-brightness gradient shows through exactly two
floating rounded cut-outs sitting in that dark field — the message box,
and a new voice/me card in the bottom-left. The bright-on-dark contrast
between the cards and the field around them is the whole look.

**The message box floats**

The message box is a rounded window straight onto your gradient, inset
from the column edges with the darker chat surface visible below and
beside it — a card in the field, not a strip flush to the edge.

**The voice card**

Your voice controls and name bar now live in one floating rounded card:
soft corners, a subtle light edge, and the darker sidebar surface showing
around all four sides. Inside it, your name row is pure gradient while the
voice header and buttons sit on a slightly cooler raised veil — a distinct
sub-surface within the card, exactly as the reference draws it.

**Toggled buttons read as ON, not as teal**

A switched-on voice button now takes a light fill with a dark glyph — the
reference's treatment for an active state — instead of a saturated accent
colour.

All icons, buttons and features are exactly where they were — this release
only changes how the surfaces underneath them are painted.

**In short**

- Dark chat/sidebar surfaces run to the window bottom — no bright strip
- The gradient glows only through the message box and the voice/me card
- Both are rounded floating cards with dark margins around them
- The voice card gets a light hairline edge and a cool raised voice zone
- Toggled-on voice buttons wear a light fill with dark ink
