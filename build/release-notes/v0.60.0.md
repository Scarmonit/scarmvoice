Owner, Admin, Member — and the admin who could demote you

Testing "Make Admin" turned up something that should never have been possible: the person you promoted could promote and demote anybody, you included. There is a role above Admin now, and it cannot be touched.

**Three roles**

- **Owner** — you. Everything: bans, password resets, clearing two-factor, deleting accounts, changing roles, deleting channels, and everything an admin can do. Nobody can demote, ban or remove you — not an admin, not another owner.
- **Admin** — the moderation role. Edit, delete and pin anyone's messages, create channels and rename them. Nothing that touches an account: no bans, no password resets, no clearing 2FA, no deleting accounts, and no changing anybody's role.
- **Member** — edit and delete your own messages. Everything else in the app works as normal; creating channels and touching other people's messages do not.

The board's Settings → Members list is yours alone now. An admin does not see it at all.

Deleting a channel is yours alone too. It destroys every message in that channel along with its files, and it cannot be undone, so it sits with the account settings rather than with the moderation tools.

All of it is enforced on the server. Hiding a button is not a permission, so nothing is stopped only by the buttons being missing — the server refuses the request as well.

**Role changes happen straight away**

- A promotion or a demotion takes effect on that person's screen immediately. No signing out, no restarting the app.
- They get a message telling them what changed and who changed it, with a button to dismiss it.
- If they happen to be offline, the new role is simply there the next time they open the app.

**Editing somebody else's message**

- Admins and owners can now EDIT another person's message, not only delete it. The ability was always meant to be there and there was no button for it.
- A message edited by somebody other than its author says so: *"edited by Scarmonit"* with the time, instead of the plain *"(edited)"* an author's own correction gets. The name at the top is still the person who wrote it, so the difference is worth being able to see.

**Resizing the panels**

- Drag the right edge of the channel list, or the left edge of the members list, to set how wide it is. Hovering the edge shows a line where you can grab it.
- Side to side only — there is no way to drag either of them vertically by accident.
- Neither can be made too narrow to use, or wide enough to squash the messages: the message area always keeps its room, including when you make the window smaller.
- Whatever you set is remembered, so it is still that way next time you open the app. Double-click an edge to put it back to normal, and the arrow keys nudge it if you would rather not drag.

**One thing that was already there**

Muting somebody just for yourself already worked, and it still does — any role, any time, from their name in the member list or the call. It only affects what you hear. Checked rather than rebuilt, so there is no second mute system to get confused with.
