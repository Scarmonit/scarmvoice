Faster from the first second

**Starting up**

- The app no longer waits for the update check before building its window. The check and the window now happen at the same time, which takes roughly half a second to a second off every launch — and when an update genuinely is waiting, everything still pauses and installs it exactly as before.
- Signing in starts earlier too: the slowest request the app makes (loading your account) now begins the instant the app starts instead of queueing behind the update check, so the board is on screen sooner.
- Every launch now writes a step-by-step timeline into the log, so if starting ever feels slow again, the log can say exactly which step took the time instead of anyone guessing.

**Small speed-ups everywhere**

- Typing in the composer does half the bookkeeping per keystroke it used to — the code-block scan was running twice for every key pressed.
- Two style rules were re-scoped so the browser no longer re-evaluates them on every new message and every flicker of the speaking indicator during calls.
- When the connection is down and the app is minimized to the tray, it now checks for missed messages once a minute instead of every four seconds — easier on your network and battery, with notifications still arriving.
